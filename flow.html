01

Executive Summary

TSF is moving from a paper-based, WhatsApp-driven operation to a fully digital platform — all under the TSF brand and domain, with no monthly SaaS fees.

Today — manual

The current operation

  • Register maintained manually by a staff member
  • Payments arrive on a personal number, verified through WhatsApp screenshots
  • Events announced in WhatsApp groups — no official registration system
  • Member data, attendance and payments exist only on paper or individual devices
  • No unified system connects the website, member records, or operations

Tomorrow — unified

The digital platform

  • One domain, three connected sites — public, members, admin
  • Members log in once: profile, payments, events, nutrition in one place
  • Payments via Razorpay with automatic receipts and records
  • Automated reminders — renewals, events, birthdays
  • Data lives in the cloud, accessible from any device — the client owns everything
One ecosystem, three doors. All three parts share the same domain, the same authentication, and the same visual identity. Members never leave the TSF ecosystem — and running costs stay near zero until the member base outgrows free tiers, realistically 2+ years away.

The four layers

Payment System

Razorpay handles the money; Supabase records it; members get receipts automatically.

Setup

  1. Business account created with business PAN and bank account
  2. KYC verified by Razorpay — usually 1–2 business days
  3. API keys generated — test mode and live mode
  4. Keys stored securely in environment variables

Methods supported

UPI — GPay, PhonePe, Paytm, BHIM Cards — Visa, Mastercard, RuPay, Amex Net banking — all major Indian banks Wallets — Paytm, Amazon Pay, Freecharge EMI — for larger payments

Auth & Security

Members see only their own data. Staff see everything. Nobody else sees anything.

Member authentication

  • Email and password — hashed via Supabase Auth, never plain text
  • Email verification required for signup
  • Session tokens (JWT) with automatic expiry
  • Password reset via email link

Admin authentication

  • Separate login page at admin.tsfclub.com
  • Same Supabase Auth — requires role: admin or staff
  • Two-factor authentication recommended — Supabase supports TOTP

Data access — Row Level Security

TableMember accessAdmin access
membersRead / write own record onlyRead / write all records
paymentsRead own payments onlyRead / write all
eventsRead published eventsRead / write all
enrollmentsRead / write ownRead / write all
attendanceRead ownRead / write all
nutrition_logsRead / write ownRead all
notifications_logRead ownRead / write all
No member can access another member's data. No unauthenticated user can access any data.

Security best practices

ConcernSolution
Password storageBcrypt hashing via Supabase Auth
Session hijackingJWT tokens with short expiry and refresh
SQL injectionParameterized queries via Supabase client
XSS attacksInput sanitization and Content Security Policy
CSRF attacksSameSite cookies and CSRF tokens
Data in transitHTTPS on all domains — auto via Vercel and GitHub Pages
Data at restEncrypted by Supabase — AES-256
Payment dataNever touches the server — Razorpay handles all card data
API keysStored in environment variables, never in code
BackupsAutomated daily by Supabase

Glossary

Plain-English meanings for every technical term in this document.

DNS
Domain Name System — the phone book of the internet that maps domains to servers
CNAME
A DNS record that points a subdomain to another domain
A Record
A DNS record that points a domain to an IP address
SSL
Secure Sockets Layer — encrypts traffic between browser and server, the padlock in the URL bar
HTTPS
HTTP Secure — the encrypted version of HTTP
JWT
JSON Web Token — a secure way to transmit authentication information
Row Level Security
A database feature that restricts access per user
Webhook
An automatic message sent from one system to another when something happens
API
Application Programming Interface — a way for two systems to talk to each other
Subdomain
A prefix on a domain — example: members.tsfclub.com
Cloud
Servers that live on the internet, accessible from anywhere
Uptime
The percentage of time a service is available
Free Tier
A free level of service from a paid provider, usually with usage limits
Razorpay
An Indian payment gateway that handles UPI, cards, and net banking
Supabase
An open-source backend platform offering database, auth, and storage
Vercel
A hosting platform optimized for modern web applications
Resend
An email sending service for developers
WhatsApp Cloud API
Meta's official API for sending WhatsApp messages programmatically
