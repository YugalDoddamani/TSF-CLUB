02 — Delivered

What is live right now.

Everything below has been built, deployed, and is running on members.tsfclub.com and admin.tsfclub.com.

Infrastructure & Security

  • Supabase project in AWS Mumbai (ap-south-1) — data stays in India as required by the DPDP Act Live
  • Database schema — members, programs, attendance, and payments tables Live
  • Row-Level Security on every table — members see only their own data, admins see everything Live
  • Role enforcement trigger — members cannot alter their own role, expiry date, or amount due Live

Authentication

  • Google sign-in for members — one-tap login, no passwords to remember Live
  • Email/password sign-in for admins, on a separate domain Live
  • Role verification — admin accounts are checked at login and routed to the admin panel Live

Member Onboarding

  • Full onboarding form — name, WhatsApp, program, joining date, height, weight, blood group, emergency contact Live
  • All 11 programs pulled from the live website — Adults and Kids grouped Live
  • Phone auto-formatting — paste any Indian number, it formats to +91 XXXXX XXXXX Live
  • Preference pills — Fighter, Fitness enthusiast, Self-defence, Athletic performance, Beginner Live

Member App (members.tsfclub.com)

  • Dashboard — progress bar, streak counter, program card, today's session action Live
  • Attendance calendar — mark or unmark any past day, keyboard accessible Live
  • Profile page — personal details, physical metrics, focus areas, membership card Live
  • Payment status display — paid / due / overdue, computed from expiry and program fee Live
  • Dark and light theme with a toggle that persists across sessions Live
  • Glass floating navigation, sticky header, and All Documents link in settings Live

Admin Panel (admin.tsfclub.com)

  • Overview tab — total members, paid, due, overdue counts and a needs-attention list sorted by urgency Live
  • Members table — searchable, filterable, sortable, with status pills Live
  • Member drawer — edit expiry, edit amount due, mark paid, log custom payment, reset onboarding Live
  • Payments ledger — reverse-chronological table of every payment, with method and notes Live
  • Manual cash / UPI entry — receptionist records in-person payments with one click Live

Deployment

  • members.tsfclub.com — Cloudflare Pages project with custom domain and SSL Live
  • admin.tsfclub.com — separate Cloudflare Pages project with custom domain and SSL Live
  • Wix CNAME records for both subdomains, automatic deployment on every push Live
03 — Pending

What remains for the launch milestone.

These are the items from the original scope that are not yet built. They are scheduled for the launch milestone and require external accounts and approvals that take time to set up.

  • Razorpay integration — live keys, checkout flow, webhooks, automated receipts, and UPI Autopay for recurring memberships Pending
  • WhatsApp Business API — business verification, phone number approval, message templates, and all automated triggers (fee reminders, welcome messages, event notifications) Pending
  • Email on the domain — hello@tsfclub.com, privacy@tsfclub.com, and transactional email via Resend for receipts and monthly summaries Pending
  • Events management — create and publish events, member interest tracking, reminder broadcasts, event archive Pending
  • Reports & insights — monthly revenue, member growth, program breakdown, dues report, CSV / Excel export Pending
  • Notification centre in member app — a log of every WhatsApp message and email sent to the member Pending
  • Coach role UI — the RLS policies are already in place; the interface for coaches to mark attendance and view their assigned members is not yet built Pending
  • Downloadable payment receipts — branded PDF receipts delivered by email and WhatsApp Pending
  • Privacy Policy and Terms of Service pages — written, published, and linked from the app Pending
  • Handover session — a walkthrough for the owner and receptionist on how to use the admin panel day to day Pending

Timeline note. WhatsApp Business API approval typically takes one to two weeks from Meta. To keep the project on schedule, that application should be submitted as soon as Milestone 1 is approved.

06 — Ownership

What the studio already owns.

As of today, with Milestone 1 live, the studio owns the following outright. Nothing is rented, nothing is locked in, nothing reverts to the developer.

  • The complete Supabase database — every member record, in the studio's own account, in the Mumbai region
  • Both live apps — members.tsfclub.com and admin.tsfclub.com, in production, under the studio's Cloudflare account
  • The full source code — every HTML, CSS, and JavaScript file in the studio's GitHub repository, with no vendor lock-in
  • Both Cloudflare Pages projects — deployment pipelines fully owned by the studio
  • The domain and all DNS records — under the studio's Wix account, with subdomains managed freely
  • The admin panel access — top-level credentials to Supabase and Cloudflare, held by the studio owner

No monthly subscription. Unlike off-the-shelf gym software, there is no per-user fee, no platform charge, and no lock-in. The only recurring costs are the ₹1,000 yearly maintenance fee and the WhatsApp message costs (approximately ₹200–400/month for a 200-member studio).
